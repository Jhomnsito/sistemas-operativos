## Publicación en GitHub

La conexión de GitHub quedó verificada para la cuenta `Jhomnsito` mediante el
conector autenticado. El usuario creó el repositorio remoto privado con un
README inicial. Se comprobó acceso de lectura y escritura y se publicó el código,
el informe y las evidencias en `main`. Se verificó la integridad de los 66 archivos
comparando el árbol Git remoto con los hashes calculados desde la carpeta local.
También se comprobaron el manifiesto y el PDF leídos desde la rama publicada.

La carga asistida conserva como antecedente el commit inicial del repositorio
remoto. El historial Git local de la preparación se conserva además en el ZIP;
no se atribuye a los integrantes trabajo histórico que no hayan confirmado.
Para actualizar el proyecto en otro equipo, se recomienda clonar el remoto
una vez cargado, evitando mezclar a ciegas historiales locales diferentes.

No es necesario enviar contraseñas, tokens ni claves por el chat. El repositorio
es privado: para compartirlo con el profesor o Andrés se deberán gestionar los
accesos con sus cuentas reales; no se añadieron colaboradores por suposición.

Los resultados de nuevas ejecuciones en `resultados_en_vivo/` quedan fuera de
Git por defecto para evitar cambios automáticos en el historial. Si una nueva
ejecución se va a usar como evidencia académica, revísenla y añadan los archivos
concretos que hayan decidido conservar.
